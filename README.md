# 📘 BIS2141 – Algorithms and Data Structures I
## Winter Semester 2025/26
### Pforzheim University (HSPF)

## 🧠 Overview

This repository contains the example project for the course  
**“Algorithms and Data Structures I (BIS2141)”** in **Winter Semester 2025/26**.  
The goal is to help students understand and apply fundamental programming concepts in **Java**, including:

- Structure and syntax of Java classes
- Methods, parameters, and return values
- **Method overloading**
- Object-oriented programming (OOP): classes and objects
- Console output and data types (`int`, `double`, `String`)

### 💻 Getting the Project from GitHub

There are **two simple ways** to get this project from GitHub —  
you can either **download it as a ZIP file** or **clone it using Git**.

#### 🟢 Option 1: Download as ZIP

1. Open the project’s **GitHub repository page** in your browser.  
2. Click on the green **“Code”** button (top right).  
3. Choose **“Download ZIP”**.  
4. Extract (unzip) the downloaded file on your computer, e.g., to  
   `Documents/BIS2141-ADS1/`.

**To open it in NetBeans:**
1. Start **NetBeans**.  
2. Go to **File → Open Project...**  
3. Navigate to the folder where you extracted the ZIP file.  
4. Select the folder and click **Open Project**.  
5. NetBeans will load the project, and you can run it via  
   **Right-click on `Demo.java` → Run File** or press `Shift + F6`.


#### 🟣 Option 2: Clone with Git

If you already have **Git** installed on your computer:

1. Copy the **repository URL** from the green **“Code”** button  
   (e.g. `https://github.com/username/BIS2141-ADS1.git`).  
2. Open **NetBeans**.  
3. Go to **Team → Git → Clone...**  
4. Paste the repository URL.  
5. Enter your GitHub credentials if asked.  
6. Choose a local directory  
   (e.g. `C:\Users\<yourname>\Documents\BIS2141-ADS1`).  
7. Click **Finish**.  
8. NetBeans will automatically recognize and open the cloned project.

#### ▶️ Running the Project

Once the project is open:
- Expand the folder `de.hspf` inside `src`  
- Right-click on **`Demo.java`**  
- Choose **Run File** (`Shift + F6`)  

You should see the output in the **NetBeans console**.
